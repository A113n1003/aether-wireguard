# 本机验证记录

日期：2026-10-10。环境：Apple Silicon、macOS 26.7.1、Command Line Tools；本地 ad hoc 签名构建。连接服务尚未包含在公开 v0.1.0 Release 中。

## 已通过

- `Scripts/check.sh`：29 项独立检查，包含配置解析、转义、旧授权取消、会话恢复，以及新服务的签名要求与不可信文件拒绝。
- `Scripts/build.sh`：客户端、Bridge、Service 编译通过；应用及两个 helper 启用 Hardened Runtime，严格签名验证通过。
- 本机冻结工具链打包、动态库重定位、完整性清单与安装后 root 所有权验证。
- 首次设置安装 LaunchDaemon；服务进程正常运行，客户端与服务双向验证精确 cdhash。
- 最终版本完成三次真实隧道启动、两次断开；间隔超过 15 分钟及客户端退出重开后，普通连接 / 断开均未请求管理员密码。
- 实际握手、ICMP 和隧道 DNS 查询通过；其他 VPN 的公网选路保持原有接口。
- 关闭按钮和 `⌘W` 均使应用切换为 `accessory`，主窗口关闭时保留原会话。菜单栏面板可操作；打开主窗口后恢复 `regular`。通过系统进程的 `activationPolicy` 验证 Dock 显示策略。
- 同一 UID 下的独立测试程序调用服务 `ping` 被拒绝，验证精确客户端 cdhash 限制。
- 安装与卸载脚本语法验证及非 root 调用拒绝通过。只读安全复核覆盖配置 FIFO、ACL、安装预检和回滚；修复后复核通过。

## 未覆盖

- 完整 Xcode XCTest 以 CI 结果为准；本机 CLT 缺少其运行环境。
- 尚未在其他系统版本、Intel、多用户切换、重启系统或异常断电下实测。
- 没有执行真实卸载、故障注入回滚、IPv6 端到端测试或 DNS 防泄漏验证。
- 本记录不构成独立安全审计或 Developer ID 发布者认证。

安装 / 更新仍需管理员授权，应用代码签名变化时需要重新绑定；日常免密码不依赖 AppleScript 的短期缓存。
