# 路线图

以下是优先级方向，不是交付时间承诺。

## 公开预发布阶段

- 补齐真实网络验收：IPv4/IPv6、全隧道/分流、DNS 恢复、取消授权与重启恢复。
- 增加配置存储、部分启动失败和生命周期回归覆盖。
- 改善低可达性、采样过期和恢复失败的诊断。

## 面向稳定发行

- 评估 WireGuardKit + Packet Tunnel Extension，收紧授权与依赖信任边界。
- Developer ID 签名、notarization、可验证的发行来源。
- 明确 Keychain 更新、配置迁移和软件升级行为。
- 验证 Intel 支持后再发布 x86_64 安装包。

## 之后评估

自动连接、Kill Switch、按应用分流和国际化需要单独的设计、实现与网络测试，当前均未实现。
